# Anki Global Kit

**by Jacob Cassidy · v{version}**

A collection of global features that supercharges Anki flashcards. It includes advanced input fields, Markdown formatting and rendering, card styles, and more that work across apps. It is especially useful for programming reviews, but works with other topics too.

Settings are saved to the `{asset_name}` file in the active Anki profile's `collection.media` folder.
